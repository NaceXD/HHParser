# 💼 Агрегатор вакансий HeadHunter (HHParser)

Современный асинхронный веб-сервис для автоматического сбора, умного локального хранения и фильтрации вакансий с платформы **hh.ru**. Проект спроектирован с упором на отказоустойчивость, высокую производительность базы данных и соблюдение стандартов «вежливого скрейпинга» (polite scraping).

---

## 🛠️ Технологический стек (Tech Stack)

* **Backend:** [Python 3.14](https://python.org) + [FastAPI](https://tiangolo.com) (высокопроизводительный асинхронный веб-фреймворк)
* **Scraping Engine:** [lxml](https://lxml.de) + [XPath](https://w3.org) (быстрый разбор DOM-дерева в обход ограничений нативных JS-движков)
* **Network Layer:** [httpx](https://python-httpx.org) (асинхронный HTTP-клиент с поддержкой устойчивых сессий)
* **Database:** [SQLite](https://sqlite.org) (режим **WAL** — Write-Ahead Logging, потокобезопасный конкурентный пул соединений)
* **Frontend:** Чистый HTML5, модульный **кастомный CSS3 (Grid/Flexbox)**, асинхронный JavaScript (Fetch API с динамической нарезкой данных)
* **Logging:** Модуль `logging` (одновременная ротация логов в терминал и файл `parser.log`)

---

## 🏗️ Архитектурные особенности проекта

1. **Фоновый асинхронный парсинг (`BackgroundTasks`)**: Сетевые запросы и парсинг внутренних карточек вакансий занимают время из-за вежливых задержек (`asyncio.sleep`). Благодаря фоновым задачам FastAPI, сервер мгновенно возвращает клиенту ответ `200 OK`, а сам сборщик продолжает тихо работать на сервере, не блокируя веб-интерфейс.
2. **Конкурентный пул соединений БД (`Queue Pool`)**: Проект использует кастомный пул на 5 соединений SQLite с поддержкой режима WAL, что полностью исключает ошибки `Database is locked` при одновременной записи из фонового парсера и чтении из API.
3. **Умный `UPSERT` (Конкатенация тегов)**: Вместо грубой перезаписи данных при совпадении ID вакансии, база данных использует связку `ON CONFLICT(id) DO UPDATE` с SQL-логикой `CASE`. Если вакансия уже была найдена по запросу *Python*, а затем вышла по запросу *Data Scientist*, ключевые слова объединятся через запятую, позволяя гибко фильтровать выдачу на фронтенде.
4. **Клиентская пагинация**: Фронтенд скачивает срез данных за один раз и нарезает массив по 10 карточек на страницу силами JS, гарантируя моментальное перелистывание без лишней нагрузки на бэкенд.

## ⚡ Быстрый запуск и развёртывание

### 1. Подготовка окружения и зависимостей
Убедитесь, что у вас установлен Python (рекомендуется 3.12+). Склонируйте репозиторий, создайте и активируйте виртуальное окружение:

```bash
git clone https://github.com
cd HHParser
python -m venv .venv

# Для Windows:
.venv\Scripts\activate
# Для macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
```

### 2. Настройка файла переменных окружения
Создайте в корне проекта файл **`.env`** и укажите маскировочный User-Agent для сетевых запросов:
```env
USER_AGENT="Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36"
```

### 3. Запуск веб-сервера
Запустите сервер разработки Uvicorn:
```bash
uvicorn main:app --reload
```

После этого приложение будет доступно по адресам:
* **Веб-интерфейс:** [http://127.0.0](http://127.0.0)
* **Интерактивная документация API (Swagger):** [http://127.0.0docs](http://127.0.0docs)

## 📡 Спецификация API-эндпоинтов

### `GET /`
Отдает сверстанный интерфейс `index.html`.

### `GET /api/vacancies`
Возвращает список вакансий из базы данных с привязанными списками навыков.
* **Параметры:**
  * `search` (str, необязательный) — Поиск по ключевому слову из поля `search_text`. Если передан — отменяет лимиты и выгружает все совпадения.
  * `limit` (int, необязательный) — Ограничение количества строк. По умолчанию, если `search` пустой, возвращает последние 20 вакансий.

### `POST /api/parser/start`
Инициализирует асинхронный фоновый скрейпинг вакансий с hh.ru.
* **Параметры:**
  * `search_text` (str, обязательный) — Ключевое слово для поиска на HeadHunter (например, `Python`).
* **Ответ:** Статус-код `202 Accepted` и JSON-сообщение об успешном добавлении в очередь задач.
